CARA MENJALANKAN
1. Letakkan folder ATSNPM di C:\xampp\htdocs\
2. Jalankan Apache dan MySQL dari XAMPP.
3. Buka phpMyAdmin: http://localhost/phpmyadmin
4. Import file ATSNPM/database/ATSNPM.sql
5. Buka aplikasi: http://localhost/ATSNPM/
6. Login menggunakan akun pada file akses.txt.

SEBELUM DEMO
- Ganti NAMA TEMAN SEBELAH KIRI dan NAMA TEMAN SEBELAH KANAN di database/ATSNPM.sql.
- Simpan screenshot tiap nomor soal ke folder Screenshot sesuai instruksi.
- Simpan pekerjaan dan ekspor database ATSNPM ke database/ATSNPM.sql.
- Bootstrap pada contoh ini menggunakan CDN, sehingga perlu internet untuk memuat tampilan Bootstrap.

CATATAN
- Nama database, tabel, dan kolom mengikuti lembar UTS untuk NPM berakhiran 018.
- Password teks biasa hanya mengikuti pola latihan dan batas kolom soal; jangan digunakan untuk aplikasi nyata.
